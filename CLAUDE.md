# rc-signals-explained

Обучающая презентация (Reveal.js + Vite) про сигналы управления в RC/FPV:
протоколы управления моторами (PWM, DShot) и протоколы связи (PPM, …).
Слайды — интерактивные SVG-схемы со слайдерами (ширина импульса, throttle,
каналы), которые пересчитывают графику в реальном времени.

## Стек

- Vite (сборка/dev-сервер)
- reveal.js (движок презентации, тема `black`)
- Никакого фреймворка — слайды это чистый HTML/SVG/JS

## Структура

Каждый слайд — отдельная пара файлов в `src/slides/`, с числовым префиксом
для порядка показа:

- `NN-name.html` — разметка `<section>...</section>` для этого слайда
- `NN-name.js` — только для интерактивных слайдов: `export function initXxxSlide()`
  с логикой рендера/слушателями (титульные слайды-разделители — только `.html`,
  без `.js`)

`src/main.js` импортирует HTML-файлы через Vite `?raw`, склеивает их в
`.slides` контейнер и вызывает init-функции — в этом файле порядок слайдов
и задаётся (просто меняй порядок импортов/элементов массива `slides`).

Текущий порядок: `01-title` → `02-motor-protocols-title` → `03-pwm` →
`04-dshot` → `05-comm-protocols-title` → `06-ppm`.

Чтобы добавить новый слайд: создать `NN-name.html` (+ `.js` если нужна
интерактивность) в `src/slides/`, импортировать в `main.js` и вставить в
нужное место массива `slides` (и вызвать init, если есть).

`index.html` — только пустой каркас (`<div class="reveal"><div class="slides">`),
слайды в него не пишутся напрямую.

- `src/style.css`, `src/assets/` — не используются активно (шаблонные остатки
  от `npm create vite`)
- `vite.config.js` — `base: '/rc-signals-explained/'` (обязателен для GitHub
  Pages, т.к. сайт живёт в подпути, а не в корне домена)
- `.github/workflows/deploy.yml` — автодеплой на GitHub Pages при пуше в `main`

## Команды

```
npm run dev       # локальный сервер (обычно http://localhost:5173/)
npm run build     # сборка в dist/
npm run preview   # предпросмотр собранного dist/
```

## Деплой

Пуш в `main` → GitHub Actions билдит и публикует `dist/` на GitHub Pages.
Источник Pages в настройках репозитория должен быть выставлен на
**GitHub Actions** (Settings → Pages → Source).

Сайт: https://jikanos.github.io/rc-signals-explained/

## Стиль кода

Слайды оформлены с явными закрывающими тегами SVG (`</line>`, `</path>` и
т.п. вместо самозакрывающихся `/>`) и многострочными атрибутами `style` —
сохраняй этот стиль при добавлении новых слайдов.
