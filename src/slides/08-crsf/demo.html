CRSF: структура пакета (UART, полный дуплекс)

992

16 каналов по 11 бит упаковываются подряд в 22 байта полезной нагрузки без выравнивания по границам байт. Выделенный квадрат — CH1, тот самый, которым управляет ползунок выше.

Addr — адрес получателя (например, полётный контроллер или приёмник), кому предназначен пакет на общей шине

Len — длина оставшейся части пакета в байтах, по ней приёмник узнаёт где заканчивается кадр

Type — тип полезной нагрузки: каналы газа, телеметрия GPS, напряжение батареи и другие виды кадров CRSF

Payload — сами данные: 16 значений каналов, упакованные по 11 бит подряд без выравнивания по байтам

CRC — контрольная сумма всего пакета, повреждённый помехой пакет отбрасывается и не отрабатывается как команда

Скорость линии (baud)

420 000

до 500 Гц
